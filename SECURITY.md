# Security

This repository is a community fork of [Azure/fetch-event-source](https://github.com/Azure/fetch-event-source),
published on npm as `@fitzyracing/fetch-event-source`. It is not maintained by Microsoft.

To report a security vulnerability in this fork, please use
[GitHub private vulnerability reporting](https://github.com/fitzyracing1/fetch-event-source/security/advisories/new)
rather than a public issue.

Vulnerabilities in the original `@microsoft/fetch-event-source` package should be reported to Microsoft as
described in the [upstream SECURITY.md](https://github.com/Azure/fetch-event-source/blob/main/SECURITY.md).
